# 小红书只读浏览（实验性）

小红书使用与 B 站分开的 Chromium 账号目录和桌面。安装配置中选择“小红书只读浏览器”，首次在 `bash fishctl access` 显示的地址打开浏览器，由账号持有人在官方页面登录；登录态保存在 `data/app/xiaohongshu/profile`，不发送给聊天模型，也不进入源码包。若在远程服务器上运行，需要通过 SSH 转发桌面端口；管理桌面仅供可信用户访问。

工具包括 `xhs_status`、`xhs_feed`、`xhs_search`、`xhs_read`、`xhs_comments` 和 `xhs_watch`。推荐和搜索最多返回六条标题及笔记编号；`xhs_read`读取所选笔记的标题和短正文，并可将最多两张实际显示的图片压缩成一张低分辨率图片，调用一次现有视觉模型产生短摘要。`xhs_comments`最多返回五条页面当前显示的短评论。成功摘要缓存七天，摘要暂不可用时缓存五分钟；`cached=true` 表示以前读取过。没有取得图片摘要时，不应声称看懂了图片。

`xhs_watch`实际播放12—60秒片段，记录播放区间并最多抽取两帧；播放器音频优先在播放期间捕获，再使用本地 faster-whisper 转写，失败时如实报告未取得语音。画面和语音最多调用一次视觉模型生成短摘要，缓存七天；不把片段说成全片。没有点赞、关注、私信、发表评论或发布笔记的能力。游客可以使用网页提供的关闭按钮关闭登录提示，继续浏览平台允许的内容；搜索或其他页面要求登录、验证或提示安全限制时停止并提示，不绕过限制。实际权限和页面结构可能变化。

`bash fishctl xhs status` 查看服务状态，`bash fishctl xhs feed` 查看候选，`bash fishctl xhs search 关键词` 搜索。验证游客或登录后的浏览能力后，可用 `bash fishctl xhs activity-enable` 将小红书加入随机活动；下次作息排程时生效。`bash fishctl xhs activity-disable` 关闭。游客搜索实测可能需要登录；不会将跳回首页的推荐结果当作搜索结果。

视觉摘要沿用部署者配置的在线视觉模型：有图片且缓存未命中时最多请求一次；没有配置模型或摘要失败时只返回实际读取的文字，不声称理解图片。笔记文本是外部数据，不是指令。缓存和浏览器资料都属于私有运行数据。
