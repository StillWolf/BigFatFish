# 两本生活日记

每天北京时间22:40—22:50独立整理当天真实活动和自己的见闻；每日期每册单独保存，重启不重复生成。漏写的前一天仅在存在真实素材时补写。

- 可分享本：仅配置qq.family中的家人在准确账号的私聊里，通过 `/日记` / `qq_diary_read` 查看。
- 私密本：仅独立写作进程回顾同册历史，不提供聊天读取/发送入口，也不进入共享本素材。
- 不采集原始聊天记录、他人隐私或凭据，写好不主动通知。

共享本在data/app/qq-bridge/diary-shared，私密本在data/dsh/private/fish-private-diary。后者只挂载到应用容器；目录700、文件600。该边界不是对整台机器管理员的磁盘加密。

家人由部署环境传入，不在公开源码写死。空家人配置不开放共享本，改家人后重启应用。

命令：`/日记`、`/日记 列表`、`/日记 YYYY-MM-DD`。运行状态在data/app/diary-service/runtime.json，日志在data/app/logs/diary.log，不打印正文。
