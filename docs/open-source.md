# 源码发布

公开的是通用源码与构建配方，不是原部署机器的磁盘快照。

```bash
bash fishctl release
```

生成dist/bigfatfish-0.1.0-source.tar.gz及校验和，包内SOURCE-MANIFEST.json记录逐文件SHA256和大小。

导出按明确清单收集源码，排除.env、data、依赖安装、嵌套Git元数据、日志、聊天与日记、登录态、客户端安装目录。若保留本机迁移前配置，还会比对已知私有值，命中就停止，报文件名而不打印值。

第三方LICENSE、CREDITS和GPL微信源码一起保留。包不含原部署者的表情收藏、头像、模型缓存或商业客户端二进制。

原先本地安装与Git元数据在被忽略的data/maintenance/open-source-backup保留，不进入发布包。普通Git仓库可直接跟踪两个桥的实际源码，无隐式子模块。

.gitignore防止普通git add带入运行数据；自行强制添加或改用其他打包方式会越过规则。发布使用导出脚本并查看清单，不把生产备份当源码上传。

本次准备不创建公开仓库、不推送远端；仓库地址与是否发布由维护者决定。
