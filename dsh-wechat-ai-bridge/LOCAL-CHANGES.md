# 小肥鱼的微信通道

基于 MIT 上游 https://github.com/Windfarer/dsh-wechat-ai-bridge ，提交
`2516b699e10213df3c1ced2fa7c0c51a8b01044b`，保留上游 LICENSE。

本地版本：0.2.4-fish.2。

- 增加 `lib/fish.js`：复用人设和静默活动日记，使用显式微信 ID 绑定家人、联系人及群。
- 微信会话和目录独立，不混入 QQ 会话；微信动作工具仅安装到微信 Agent，不注册为宿主全局工具。
- 私聊、群内 @ 免主动聊天配额；未 @ 的群聊允许选择 `[不回复]`。主动回合每分钟最多10次，主动出站每分钟默认最多3条。
- 消息游标同时记录秒级时间与消息 ID，避免同一秒内的后续消息漏处理。
- 生物钟通过微信独立队列投递提示，五分钟前的旧提示不补发。三餐与联网活动仍只执行一份。
- 图片、当前聊天历史、活动读取、当前工作区文本文件读取，均绑定当前微信会话。
- `wechat_say` 调用现有本地 TTS，并发送音频文件；不声称实现微信原生语音气泡。
- 默认没有绑定联系人或群，不因昵称自称而授予家人身份。绑定文件可热更新，不需要重载 QQ。

配置位置和操作入口见项目 `docs/wechat-setup.md`。
